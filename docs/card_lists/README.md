## 收录规则

- 只统计 `script_class="CardData"` 的 `.tres`，不统计效果、条件和牌堆资源。
- `allowed_classes` 存在时优先按该字段归类，否则按 `card_class` 归类。
- 德鲁伊正逆位属于同一张资源，在同一行展示两个牌面。
- 数值和说明来自资源文件；运行时效果实现仍以对应 GDScript 为准。
