# 战士牌表

> 数据来源：`resources/cards/*.tres` 中的 `CardData` 资源。默认值按 `scripts/cards/card_data.gd` 解释。

- 已实现：18 张；设计中：5 张
- “武器射程”表示实际射程还会受角色、装备、状态和地表效果影响。
- 已实现卡牌的完整规则文本保持与资源中的 `description` 一致。

## 关键词

- **切换武器**：交换当前武器与备战武器；备战武器为空时无法切换。
