# 卡牌更新日志

本日志用于记录玩家牌与中立/诅咒牌的新增、调整、文本修正和删除。最新变更置于最前；一张卡牌的一次独立变更占一行。

## 填写规则

- 日期使用 `YYYY-MM-DD` 格式。
- 变更类型使用：`新增`、`平衡`、`机制`、`文本`、`删除` 或 `文档`。
- “变更前”和“变更后”应写明具体数值或规则文本；新增牌的“变更前”、删除牌的“变更后”填写 `—`。
- “关联文件”优先链接对应的 `resources/cards/*.tres`；涉及效果实现时可同时链接 GDScript。
- 同一批变更按职业、卡牌名称排列，方便和各职业牌表核对。
