# 主菜单与安全返回 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现正式主菜单、只读卡牌图鉴、独立显示设置，以及地图／战斗安全返回主菜单。

**Architecture:** 主菜单只负责展示；导航协调器负责切换，冒险会话提供窄的保存与恢复接口。图鉴和设置分别拥有独立数据服务及界面。战斗返回通过安全检查后重载已保存检查点，不保存半途战斗状态。

**Tech Stack:** Godot 4.7.2、GDScript、Control/Container、Resource、ConfigFile、现有场景式诊断。

**Spec:** `docs/superpowers/specs/2026-09-21-main-menu-design.md`（用户已确认）。

## Global Constraints

- 沿用羊皮纸、黑色笔触的视觉风格，按职责拆分界面、导航、设置和图鉴数据。
- 第一版保留现有队伍与新冒险生成规则，不增加职业选择、多存档槽、账号、云存档或图鉴解锁系统。
- 不建设任意回合战斗快照。
- 设置限窗口模式与分辨率。
- 窗口分辨率预设：1280×720、1600×900、1920×1080。
- 显示设置应用后提供限时确认，15 秒未确认自动回退；只有确认后持久化。
- 主菜单查询状态不得调用 `AdventureSession.ensure_run()`。
- 不为菜单升级存档格式；保留旧版、未来版本、备份与待处理事务保护。
- 不修改六边形地图、危险成长、卡牌数值或商店随机序列。
- 产品代码只在用户审阅计划并确认执行方式后修改；当前工作区实施，不自动创建另一个项目副本。每任务验证后可本地提交，不推送。

## Review Focus

1. 同一进程从战斗返回后继续：不能保留旧英雄资源引用、半途伤害或手牌（Task 1、5）。
2. 双击、确认框开启后状态改变、场景载入失败：不能重复新建、跳过事务或把 UI 永久锁住（Task 2、5）。
3. 未来版本仅存在于备份、磁盘写入失败：不能覆盖受保护内容或丢失原有内存进度（Task 1）。
4. 退出设置确认框、切页或关闭页面：未确认显示设置必须回退，不能污染持久配置（Task 4）。
5. 图鉴多职业、逆位名搜索、资源重映射导出：必须找到卡牌，且不依赖战斗或把基础牌加入奖励（Task 3、6）。
