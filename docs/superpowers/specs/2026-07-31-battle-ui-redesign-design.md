# 战斗场景 UI 重做设计规格

日期：2026-07-31

## 目标

按照 `D:/设计与开发文档/总之是卡组/新UI样例.drawio.html` 的信息层级重做战斗 HUD，在保留现有战斗交互与结算入口的前提下，提高可读性、信息密度和视觉完成度。

设计必须满足：

- 以 `1280x720` 为基准，最低支持 `960x540`。
- 支持 `16:10`、`16:9` 和 `21:9`，超宽屏额外空间主要扩大战场。
- HUD 不遮断核心战场交互，战场仍可拖动与缩放。
- 动态装备行动、手牌数量和详情内容不能移动回合控制按钮。
- 沿用硬派西方奇幻、磨损木材、黑铁、黄铜和羊皮纸风格，并适当提高功能色饱和度。

## 场景架构

`BattleScene` 继续负责控制器绑定、输入模式和战斗流程，不再直接承载全部 HUD 排版。新增 `BattleHudRoot` 作为战斗界面组合层，包含以下独立子场景：

| 子场景 | 职责 |
| --- | --- |
| `BattleTurnOrderBar` | 展示本轮已锁定的完整行动序，标识当前和已行动单位。 |
| `BattleDeploymentPanel` | 展示待部署角色和开始战斗入口，部署结束后隐藏。 |
| `BattleDetailPanel` | 统一展示卡牌、装备、友方、敌人、对象和地形详情。 |
| `BattleBottomHud` | 当前角色、生命、AP、命令、装备、资源、状态与特殊区入口。 |
| `BattlePileButton` | 牌库和弃牌堆共用的圆形牌堆按钮组件。 |
| `BattleEquipmentActionsPopup` | 多功能装备的向上展开面板。 |

HUD 子场景只读取 `BattleController` 和 `BattleUnitState`，通过信号请求移动、基础攻击、结束回合、装备行动和特殊区操作。所有领域校验与结算继续经过 `BattleController`。

## 布局

### 战场

- `MapView` 保持全屏，位于 HUD 下层。
- 地图自动适配时为顶部行动序、底部 HUD、可见部署面板和可见详情面板保留安全区域。
- 安全区域只影响初始适配和视图重置，不缩小地图数据边界。
- 玩家可以拖动战场，把被 HUD 临时遮住的边缘区域移动到可见范围。

### 左上区域

- 圆形菜单按钮固定在左上安全边距内。
- 部署面板位于菜单按钮下方，显示 3 至 4 名冒险者的部署状态。
- 部署完成并进入战斗阶段后，部署面板隐藏且不再占用输入区域。
- 战斗日志不再常驻左侧栏；日志入口放入菜单，必要的即时反馈使用短时通知。

### 顶部行动序

- 横向轨道位于顶部居中，标准宽度约为视口宽度的 `34%`，限制在 `360-620 px`。
- 显示本轮完整锁定顺序。当前单位使用琥珀金高亮，已行动单位降低亮度。
- 友方头像使用翡翠绿边框，敌方头像使用深红边框。
- 下一轮开始时再依据新的锁定顺序整体刷新。
- 头像支持悬停预览与点击锁定详情，但不会改变底部当前角色 HUD。

### 右上详情

- 标准宽度为 `280-340 px`，高度不超过视口的 `52%`。
- 未查看任何内容时隐藏，不保留空白占位。
- 支持卡牌、装备、友方角色、敌人、战场对象和地形。
- 敌人详情额外显示公开意图、牌区数量和已见牌。
- 卡牌详情显示图像、费用、品质、类型、目标、范围和完整规则文字。
- 装备详情显示槽位、品质、当前形态、基础伤害、范围、伤害类型、配对/双面组件、描述和运行时摘要。

### 底部 HUD

- 高度约为视口的 `26%`，限制在 `176-224 px`。
- 上层功能带从左至右依次为：
  - 附魔区。
  - 装备与装备行动。
  - 当前角色生命和 AP。
  - 移动、基础攻击和结束回合。
  - 职业资源与主要状态。
  - 诅咒区。
- 当前角色头像从生命/AP 区上沿向战场突出，不改变功能带高度。
- 下层为木制手牌底板，手牌横向排列并在自身区域内滚动。
- 弃牌堆和牌库使用圆形按钮，分别压在手牌底板左右端。
- 底部 HUD 始终绑定当前行动单位；部署阶段绑定当前待部署角色。详情面板的查看对象不会替换它。

## 装备区与多功能装备

- 装备区显示当前武器、形态、四个装备槽摘要和运行时状态。
- 单一可用装备行动直接显示在装备区。
- 存在多个可用行动时，装备区显示一个“展开”图标，不使用滚动条。
- 点击展开后，`BattleEquipmentActionsPopup` 从装备区上方向战场弹出。
- 标准宽度使用两列按钮；紧凑宽度自动改为单列。
- 弹出面板通过列数、按钮高度和紧凑文字适配安全区域，不提供滚动。
- 执行装备行动、切换当前单位、进入结算锁、点击空白战场或再次点击展开按钮时关闭。
- 万花筒的万象和硬币预押、黏菌渗流等多行动装备使用同一组件。

## 详情交互

- 悬停可检查对象时显示临时预览。
- 点击对象后锁定详情。
- 锁定期间其它悬停不覆盖内容。
- 点击空白战场或详情关闭按钮解除锁定并隐藏面板。
- 手牌、行动序头像、装备槽、特殊区列表、战场单位、对象和地形均接入同一详情请求接口。
- 牌库、弃牌堆、附魔区和诅咒区继续通过列表窗口展开；列表条目使用详情面板展示完整信息，tooltip 只保留简短提示。

## 命令与特殊区

- 移动、基础攻击、结束回合、菜单、附魔、装备、资源、诅咒、牌库和弃牌堆使用图标或图标加短文字。
- 陌生图标必须提供 tooltip。
- 结束回合与手牌滚动区域的矩形不能相交。
- 附魔区显示附魔牌数量，并打开只包含附魔内容与相关行动的列表。
- 弃牌堆列表保留弃牌与放逐内容，但不再混入附魔区。
- 诅咒区显示诅咒、畸变、负荷和咒波的紧凑摘要。
- 职业资源区显示当前角色资源和主要状态，可执行职业行动留在该区域。

## 美术方向

沿用现有磨损木材、黑铁、黄铜、皮革和羊皮纸材质。新资源不包含文字，排版由 Godot 控件完成。

新增资源：

- 可九宫格拉伸的木制底部 HUD 面板。
- 黑铁与黄铜通用功能面板框。
- 顶部行动序金属横轨。
- 右上详情面板框。
- 菜单、移动、攻击、结束回合、附魔、装备、状态和诅咒图标图集。
- 当前角色头像环、友方行动序头像框和敌方行动序头像框。

功能色：

| 用途 | 色彩 |
| --- | --- |
| 友方 | 高饱和翡翠绿。 |
| 敌方 | 深红。 |
| 当前行动 | 琥珀金。 |
| 附魔 | 青蓝。 |
| 装备 | 黄铜金。 |
| 诅咒 | 紫红。 |
| 不可用 | 降低明度和饱和度，并保持可辨识轮廓。 |

现有牌库、弃牌堆、AP 槽和手牌框继续复用。新旧资源通过亮度、黄铜色和边框厚度统一。

## 响应式规则

### `960-1099 px`

- 底部六段功能区压缩文字和间距，保持固定高度。
- 行动序缩小头像并允许横向滚动。
- 详情面板作为右上覆盖式浮层，不参与战场水平布局。
- 多功能装备展开面板使用单列紧凑按钮。

### `1100-1600 px`

- 使用标准样例比例。
- 多功能装备展开面板使用两列按钮。
- 详情面板采用 `280-340 px` 宽度。

### 大于 `1600 px`

- 底部功能区与手牌底板限制最大宽度并保持居中。
- 额外空间扩大战场和左右安全边距，不按宽度同比放大字体或按钮。

## 状态与错误处理

- 没有当前单位时，底部 HUD 显示空状态并禁用战斗命令。
- 敌方行动期间，玩家命令禁用但特殊区和详情仍可查看。
- 结算锁期间关闭装备展开面板和目标选择弹窗，防止陈旧操作。
- 被查看对象失效或死亡时，未锁定详情自动隐藏；锁定详情显示最终状态后允许手动关闭。
- 装备行动在点击到结算之间失效时，由控制器拒绝并通过短时通知显示原因。

## 测试

新增真实场景 UI 诊断，覆盖：

- `960x540`、`1280x720`、`1920x1080`、`2560x1080`。
- 固定区域不越界，关键输入区域不重叠。
- 战场保留可点击中心区域，地图适配考虑 HUD 安全区。
- 部署面板在开战后隐藏。
- 行动序按本轮锁定顺序显示，当前和已行动状态正确。
- 底部 HUD 始终绑定当前行动单位或待部署角色。
- 详情悬停、锁定、空白关闭和失效对象处理。
- 单功能装备不显示展开按钮。
- 多功能装备展开全部行动，弹窗不改变底部 HUD 几何位置。
- 万花筒全部装备行动在 `960x540` 可操作。
- 手牌数量变化不移动牌库、弃牌堆或结束回合按钮。
- 新 PNG 导入成功。
- 严格编辑器加载、战斗流程、德鲁伊武器、完整战斗加载诊断通过。

## 非目标

- 本轮不修改卡牌、装备或职业机制数值。
- 本轮不修改战斗结算时序、AI 规划或地图规则。
- 本轮不重做大地图和战斗外背包 UI。
- 本轮不增加战斗动画、音效或本地化系统。
