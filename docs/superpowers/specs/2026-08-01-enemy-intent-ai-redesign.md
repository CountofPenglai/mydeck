# 怪物意图与战术 AI 重构规格

日期：2026-08-01

## 目标

将怪物当前锁定具体卡牌、目标和路径的意图系统，改为公开战术方向、执行时动态选取行动的系统。玩家能够预判怪物本回合的行为倾向，但不能提前获知每一张牌和每一个目标；怪物仍通过评分搜索选择当前局面的较优行动，并能完成强化后攻击、接近后连击等短连携。

本系统适用于普通敌人、精英和 Boss。Boss 的阶段转换、强制动作和场景机制仍作为独立公开机制，不占用通用意图槽。

## 意图类别

怪物使用以下七类意图：

| 意图 | 行为范围 |
| --- | --- |
| 接近 | 移动到能够攻击冒险者的位置；必要时可在到位后使用符合接近意图的轻量攻击。 |
| 防御 | 使用护甲、治疗、减免、抵挡、保护友军或其它生存类卡牌。 |
| 攻击 | 使用攻击类卡牌和武器打击，优先提高总伤害与有效命中。 |
| 功能 | 使用附魔、畸变、资源生成、强化、换武器及其它辅助行动。 |
| 施咒 | 使用诅咒牌、咒害及明确标记为施咒的怪物专用牌。 |
| 逃离 | 远离近战威胁并尽量回到武器理想距离；仅由远程或明确允许逃离的敌人选择。 |
| 收割 | 接近并追杀残血目标，显著提高击杀和连续攻击的评分。 |

## 回合意图结构

每个怪物在意图生成阶段锁定并公开两个主要意图和一个备用意图：

```text
主要意图一 -> 主要意图二 -> 备用意图 -> 结束回合
```

- 主要意图一通常是轻量铺垫，例如接近、功能或防御。它使用独立的较低 AP 预算，避免无意耗尽全部 AP。
- 主要意图二是本回合核心行动，可以消耗全部剩余 AP，并允许连续打出多张牌。
- 两个主要意图结束后，只要仍有 AP，便执行一次备用意图计划。
- 备用意图计划结束后，无论是否还有 AP，怪物都结束回合。
- 某个意图没有合法行动、目标全部失效或无法支付任何候选行动时，立即进入下一个意图。
- AP 已耗尽或所有手牌均无合法用途时，可以提前结束回合。

意图锁定的只有类别和公开说明。具体卡牌、目标、移动路径、换武器选择与连招在该意图开始执行时，根据最新公开战场状态重新规划。

## 动态小型计划

每个意图执行时生成一段受当前意图类别约束的小型计划：

- 计划可包含移动、换武器、基础打击和多次出牌。
- 候选行动必须与当前意图匹配；其它意图标签不参与本阶段评分。
- 使用有限束搜索保留少量高分序列，限制搜索深度和候选移动格数量，避免组合爆炸。
- 每执行一步后重新校验余下计划。状态明显变化或动作失效时，只在当前意图类别内重新规划。
- 不允许在执行中静默切换为其它意图。当前类别无解时进入下一个公开意图。
- 主要意图一的 AP 预算由 AI 档案给出，默认保留足够 AP 供主要意图二使用；该预算不是额外资源，也不能突破当前 AP。

连携通过卡池条目的前置标签、产出标签和连携加值表达。例如功能牌产生 `damage_buff`，后续攻击牌需要或偏好 `damage_buff`，使搜索器倾向于先强化再攻击。主要意图二会读取主要意图一已经造成的真实状态变化，因此跨意图连携不依赖预锁定具体卡牌。

## 怪物专用卡牌副本

建立怪物专用卡牌池，不让 AI 直接依赖玩家职业牌的复杂资源与职业循环。副本可以保留名称、风味与主要效果，但应简化以下内容：

- 依赖玩家专属资源、特殊区或多次选择窗口的效果。
- 对玩家有构筑意义、对单场怪物实例没有稳定收益的效果。
- 会导致 AI 递归选择、长时间等待或难以公开说明的交互。

怪物副本是独立 `CardData` 资源；怪物卡池配方通过 `EnemyCardPoolEntry` 引用副本。玩家奖励、商店和职业卡池必须过滤怪物专用资源。

## 多意图标签与评分隔离

`EnemyCardPoolEntry` 为一张牌保存多个意图评分条目。一张牌可以同时属于攻击、防御或功能等多个类别，但每个类别拥有独立基础分和数值权重。

示例：一张“造成伤害并获得护甲”的牌可以同时具有攻击与防御标签。

- 处理攻击意图时，只读取攻击评分，评估伤害、击杀和攻击连携。
- 处理防御意图时，只读取防御评分，评估护甲、减伤和存活收益。
- 不把同一张牌在其它标签下的价值叠加到当前评分。
- 没有当前意图评分条目的牌不能进入候选集。

数值型卡牌记录可估算的基础量，包括伤害、护甲、治疗、抽牌、移动、控制、咒波或诅咒收益。运行时评分器再根据目标数量、实际缺失生命、过量护甲、可达距离、击杀概率和状态免疫进行折算。无法可靠量化的特殊牌使用显式基础分和局面条件，不通过描述文字推断。

## AI 档案

新增可复用的 `EnemyAIProfile` 资源，由 `EnemyData` 引用。档案包含：

- 七类意图的基础权重与允许开关。
- 主要意图一的 AP 预算或保留 AP。
- 理想攻击距离、近战危险距离和容忍偏差。
- 残血阈值、收割阈值和目标优先级。
- 防御、进攻、逃离、击杀及连携的局面修正。
- 意图重复惩罚和少量随机扰动范围。

基础档案至少包括：

| 档案 | 倾向 |
| --- | --- |
| 均衡型 | 接近、功能、攻击之间保持平衡，优先稳定连携。 |
| 远程控距型 | 近战威胁进入危险距离时提高逃离；处于理想距离时优先攻击和功能。 |
| 残血固守型 | 生命低于阈值时明显提高防御、治疗和逃离权重。 |
| 残血狂攻型 | 生命低于阈值时降低防御，提高攻击、收割和高风险行动权重。 |

敌人引用基础档案，并可覆盖少量参数。敌人差异应优先由档案参数和卡池构成产生，不复制整套行为脚本。

## 意图选择评分

意图生成只读取 AI 可见的公开信息和自身完整状态，包括：

- 当前生命、护甲、状态、AP、手牌类别与武器范围。
- 冒险者位置、公开生命、护甲、状态与可达格。
- 当前是否存在可用防御牌、攻击牌、功能牌或诅咒牌。
- 是否有残血目标、近战威胁、理想射击位置或可形成的短连携。

意图评分先由档案权重产生，再按局面修正。选择两个主要意图时允许重复，但应施加重复惩罚；只有确实适合连续攻击、连续防御或连续施咒的敌人才会稳定选择相同意图。备用意图优先选择能利用剩余 AP、且在主意图失效时仍有较高可用率的类别。

收割不是普通攻击的永久替代。只有存在低于档案收割阈值的合法目标时才进入高分候选，并在目标恢复或死亡后按当前局面重新选择具体目标。

## 移动与目标

- 接近使用六边格整数距离和实际路径费用，寻找最小代价的可攻击位置，而非单纯靠近目标坐标。
- 逃离最大化与近战威胁的安全距离，同时尽量保留当前或下一步攻击能力；不能移动的远程敌人不会空转选择逃离。
- 收割允许把移动和攻击放在同一意图计划中，并提高对低生命目标的击杀评分。
- 攻击仍遵循合法目标、视线、武器模式和不误伤规则。
- AI 不读取玩家手牌内容、牌库顺序或其它未公开信息。

## Boss 与特殊动作

Boss 阶段转换、福音、圣徽、克拉肯子回合、冠军换武冲锋等强制机制保留独立执行入口：

- 强制动作可以在通用意图前后执行，但必须在 UI 中单独公开。
- 强制动作不伪装成七类普通意图，也不占据三个意图槽。
- 特殊动作完成后，通用意图根据实际剩余 AP 和战场状态执行。
- 特殊动作导致单位死亡、阶段结束或行动权转移时，取消未执行的通用意图。

## UI

棋子头顶只显示两个主要意图的简洁图标；备用意图使用较小的“备”标记。详情面板显示：

```text
主要：功能 -> 攻击
备用：防御
```

详情说明每种意图允许的行为，不显示具体卡牌、目标、路径、AP 分配或预计伤害。意图执行时高亮当前阶段；进入下一阶段后更新高亮，但不改写本回合已公开的意图类别。

## 数据与代码边界

建议新增或调整以下结构：

- `EnemyIntentCategory`：七类意图的统一枚举。
- `EnemyCardIntentRating`：一个意图类别对应的基础分、量化值和评分参数。
- `EnemyCardPoolEntry`：保存多项意图评分、连携标签、目标偏好与复制限制。
- `EnemyAIProfile`：保存敌人决策权重和阈值。
- `EnemyIntentPlan`：保存两个主要意图、一个备用意图、当前阶段和公开说明，不再保存具体卡牌步骤。
- `EnemyIntentPlanner`：负责回合意图选择及单意图动态小型计划。
- `TacticalEnemyBehavior`：负责按固定三个阶段执行，并在备用意图后结束回合。

结构化行动步骤继续使用现有内部字典时必须限制在规划器内部；若跨模块传递或字段继续扩展，应升级为 typed `EnemyIntentAction`，避免字符串键和 Variant 类型错误。

## 迁移与兼容

- 为第一、二章所有怪物卡池条目补齐意图评分；不能依赖 `CardData.card_type` 自动代替正式标签。
- 可以提供一次开发期诊断：列出没有意图评分、引用玩家复杂机制或可能进入玩家奖励池的怪物牌。
- 旧存档缺少 AI 档案时回退到均衡型，不应导致战斗无法加载。
- 旧的具体步骤意图 UI、目标预告和累计预计伤害摘要应移除或改为类别摘要。
- 怪物显化选择仍可按已有规则预先锁定；它属于回合开始机制，不属于三段行动意图。

## 验证

- 每个普通敌人每回合得到两个主要意图和一个备用意图，且计划中不存在具体卡牌、单位或格子引用。
- 主要意图一遵守 AP 保留，主要意图二可连续出牌；备用意图执行后必定结束回合。
- 锁定意图后改变手牌、目标位置或护甲，执行时仍能在原意图类别内选择新的合法优解。
- 多标签卡牌在不同意图中只读取对应评分，不发生跨标签重复计分。
- 强化与攻击组合的评分高于错误顺序，且不会递归或无限出牌。
- 远程控距型在近战贴身时倾向逃离；残血固守型与残血狂攻型在同一局面产生明显不同选择。
- 只有存在合法残血目标时收割才显著升权。
- 第一、二章所有卡池条目均有至少一个意图评分；怪物专用牌不会进入玩家奖励池。
- Boss 强制机制、显化、换武器和阶段转换仍可与三段意图顺序共存。
- 意图 UI 不再泄露具体牌、目标、路径和预计数值。
- 在项目文档规定的 Godot 测试环境中运行静态诊断、意图单元测试及最小战斗加载测试。
